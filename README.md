# Yiqun Tong

[Academic homepage · 童逸群](https://yiquntong.github.io/)

This academic homepage is a static site. Open `index.html` in a browser to preview it. The text, paper titles, and external links are in `index.html`. The portrait, stylesheet, and fonts are in `assets/`.

## Publish with GitHub Pages

1. For a personal or organization homepage, create a repository named `<owner>.github.io` under the matching GitHub account. A project site can use a different repository name.
2. Put `index.html`, `robots.txt`, `sitemap.xml`, `assets/`, `cv/`, and `.nojekyll` in the root of the publishing branch.
3. In **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, select the branch and **/(root)**, and save.
4. When the deployment finishes, open **Visit site** on the Pages settings screen.

Edits pushed to the publishing branch update the site. The CV PDF and its LaTeX source are in `cv/`. The research statement links to OneDrive.

The CV builds with pdfLaTeX. The Chinese name uses the TeX Live packages `cjk` and `arphic`.
